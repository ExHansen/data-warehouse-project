# data-warehouse-project
This project is me practising to be an aspiring data engineer, starting with how to build a data warehouse from Data With Baraa

Link youtube: https://youtu.be/9GVqKuTVANE?si=n_TRcRaQvGJP6PuU


In this project, I've learned about What is Data Warehouse, ETL/ELT, Project Planning, Analyzing Requirements, Schemas, Data Catalog, Data Architecture (Data Warehouse, Data Lake, Data Lakehouse, Data Mesh) using method like Inmon, Kimball, Data Vault, Medallion Architecture.

In this project, we're using Medallion Architecture where it's using Bronze, Silver, and Gold Layer.

Define Naming Convention: https://github.com/GoldenbergLab/naming-and-documentation-conventions

This project involves:
- Data Architecture: Designing a Modern Data Warehouse Using Medallion Architecture Bronze, Silver, and Gold layers.
- ETL Pipelines: Extracting, transforming, and loading data from source systems into the warehouse.
- Data Modeling: Developing fact and dimension tables optimized for analytical queries.
- Analytics & Reporting: Creating SQL-based reports and dashboards for actionable insights
